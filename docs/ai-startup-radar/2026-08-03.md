## 一、方法、口径与数据限制

本期先复核上一期公司，再以“Agent / Coding Agent / AI SWE / RAG 与 Context / 企业 Agent 平台 / Computer Use / 语音与多模态 Agent / 个人 Agent / 相关 Runtime 与 Harness”为关键词扩展检索。每家公司优先核验官网、产品文档、GitHub、论文、融资方或投资数据库，再用招聘平台和媒体交叉检查大陆主体、融资阶段、人数及商业信号。

严格名单同时满足：在中国大陆有实质研发或经营主体；最新公开融资不晚于 B 轮；任何可信人数口径均未达到 100；产品不是成熟公司内部项目，也不是纯模型、芯片、算力、外包集成或概念 Demo。只要出现可信的 100 人及以上口径，即使另有较小口径，也移入边界名单。

需要特别说明：

- 招聘平台的 `20–99`、`0–20` 是区间标签，不等于审计后员工数；本报告保留抓取/更新时间，并把互相冲突但都低于 100 的口径写出。
- “注册团队”“项目数”“访谈时长”“GitHub Stars”“意向订单”均不等于付费客户或收入。商业数字若来自公司或商业推广稿，均标成“公司自报”。
- 融资金额、客户收入、续费与部署数据大多未经审计；融资可以反映阶段与资金信号，但不能直接推算现金 runway。
- 部分招聘页面、融资数据库和产品页面会持续更新，本报告记录的是统计截止时可见状态。
- 本期没有为了达到数量下限纳入证据不足项目；新增入选主要来自扩大严格扫描覆盖，而非都在本周新成立。

## 三、本周结论

### 最值得跟踪的 4 家

1. **词元无限 / InfCode**：本期资本与招聘信号最强，且技术最贴近 Coding Agent Harness——任务分解、工具执行、容器隔离、上下文管理、多 Agent 协作与评测都有公开代码或论文承载。下一步关键不是再看融资，而是验证企业付费、交付复用率和公开基准的可复现性。
2. **BetterYeah AI**：在严格名单中，企业 Agent 平台的权限、插件、知识库、数据库、MCP、日志与流程编排覆盖最完整，招聘也最活跃。关键变量是近半年缺少公开更新日志，以及“近 10 万企业团队”与真实付费、续费、生产部署之间的落差。
3. **VUI Labs / SaySo**：语音输入产品已上线，融资与小团队口径清晰；若其 Luna/VUI 平台能开放 API、会话状态、工具调用和端侧/云侧指标，将从“语音产品”跃迁为值得专项跟踪的语音 Agent Runtime。当前证据还不足以证明这一跃迁。
4. **Mindverse / Second Me**：开源与论文验证最丰富，个人上下文、GraphRAG、本地部署和动态 UI 都与 Personal Agent Harness 高度相关；但公司主体、研究组织、消费产品之间的边界，以及商业模式仍不够透明。

### 行业层判断

- 最稀缺的不是又一个 Agent 前端，而是能被独立验证的 **执行可靠性、权限与审计、上下文生命周期、失败恢复、评测和可观测性**。严格名单中，词元无限与 BetterYeah 的公开材料对此覆盖最深。
- 垂直 Agent 正在从“生成内容”转向“接管流程”：Mizzen 接管研究计划、招募、访谈与分析，GrowthGPT 接管投放计划、执行、监控与调优。它们的护城河更依赖工作流数据、权限边界和闭环效果，而非单次生成质量。
- 商业证据仍普遍偏弱。能看到产品上线、招聘、融资和公司自报案例，但可核验的合同、付费席位、续费、生产部署和净收入留存极少。
- 基础模型升级会快速商品化文案生成、通用问答和简单工具调用。相对耐久的部分是客户系统连接、领域状态机、审计/合规、评测数据和可复用的执行基础设施。
- 定制交付风险仍需持续观察。项目数、行业案例和大客户名单若没有标准版本、部署周期、毛利或复用率佐证，不能证明平台收入已经高于人力交付收入。

**技术路线与 Harness/Runtime 关联**

- InfCode 开源仓库提供命令行 Coding Agent，公开代码涉及任务拆解、工具调用、容器镜像、子 Agent/多 Agent 和上下文处理；MIT 许可。本期抓取约 60 Stars、4 Forks、17 次提交，规模仍很早，不能用 Stars 代替采用率。

- 这是严格名单中与 Agent Harness 最直接的一家：模型可替换，而容器、工具权限、任务状态、上下文压缩、失败恢复、轨迹评测和可观测性是更持久的技术层。

**产品与商业信号**

- 产品已开源并有官网/论文，不是概念 Demo；近期融资和 Agent 架构招聘构成明确扩张信号。

- 公开开源采用量仍小；论文基准与真实仓库、长任务可靠性之间存在距离。
- Coding Agent 性能高度受基础模型进步影响，若差异主要来自提示和模型路由，容易被商品化。
- 企业项目可能要求大量私有工具接入和工程交付；需要确认标准 Harness 收入与定制人力的比例。

**主要风险**

- 通用系统级语音输入和基础模型实时语音会快速商品化单点功能。
- 若核心仍是输入法/转写，而非带状态、工具与治理能力的 Runtime，技术关联会弱于当前跟踪主题。
- 人数、轮次标签和品牌/主体资料存在口径冲突，商业证据仍主要来自公司侧。

## 八、结论摘要

本期不是“全面爆发”的一周，而是资本和产品证据分化的一周。词元无限用连续融资强化了 Coding Agent Harness 的投入信号；BetterYeah 仍是企业 Agent 平台里组件覆盖最完整的早期团队；VUI 与 Mindverse 分别在语音和个人 Agent 上拥有真实产品/开源技术，但商业与组织证据滞后；Mizzen 和 GrowthGPT 展示了垂直 Agent 接管完整业务流程的方向，不过关键商业数据仍主要为公司自报。

严格名单没有采用任何已知 100+ 人数口径的公司，也没有把注册量、Stars、推广稿客户数或效果百分比当成已确认收入。本期最重要的后续工作，是把“产品存在”和“融资发生”进一步推进到可验证的生产可靠性、付费、续费、部署复用与审计证据。
