## 一、方法、口径与数据限制

- 招聘平台的 `0–20`、`20–99` 是公司或平台区间标签，不是审计人数；动态职位数还会受页面合并、下架和抓取时间影响。

## 三、本周结论

### 最值得重点看的 5 家

1. **词元无限 / InfCode**：Coding Agent Harness 关联最直接，公开代码和论文覆盖工具执行、容器、多 Agent 与评测；融资和企业场景信号较强，但开源维护停滞、真实付费与复用率仍待验证。
2. **BetterYeah AI**：严格名单中企业 Agent 编排、知识、MCP、权限和日志覆盖最完整；关键缺口依然是注册团队与付费、续费、生产部署之间的桥接数据。
3. **VUI Labs**：新确认的 Agent、API、工具轨迹和按分钟定价，使其不再只是语音输入产品；但案例没有明确客户名，第三方部署与留存证据仍弱。
4. **Mindverse / Second Me**：A 轮和 App 更新改善资金与产品连续性，持续学习、多 LoRA 推理、个人上下文和动态 UI 与 Personal Agent Harness 深度相关；开源仓库停滞和主体关系仍是折价项。
5. **LeapMind Growth / GrowthGPT**：公开收费入口、审批、Guardrail、审计和跨广告平台执行构成较完整的垂直 Agent 闭环；独立采用证据仍只到“已上架、零评价”，客户与效果主要来自公司自报。

### 行业层观察

- **技术价值继续向执行控制面集中。** 权限、沙箱、状态恢复、长上下文、工具轨迹、评测和可观测性比单次生成更难被基础模型直接吞没。词元无限、BetterYeah 和 VUI 当前覆盖最深。
- **公开定价不等于商业验证。** VUI 与 GrowthGPT 都出现更明确价格，但严格意义上的客户付款、续费、生产用量和毛利仍未出现独立证据。
- **开源热度和维护活跃度正在分化。** Second Me 有高 Stars、InfCode 有基准论文，但两仓库均长期无新推送；若闭源产品持续迭代，应进一步解释开源版与商业版的关系。
- **垂直 Agent 的壁垒在闭环数据而非文案。** GrowthGPT 的渠道反馈、Mizzen 的访谈轨迹、VUI 的通话工具轨迹都可能形成数据飞轮；若主要依靠人工运营和客户定制，这种壁垒会转化为交付负担。
- **基础模型商品化压力仍高。** 通用问答、转写、文案、简单 RAG 和基础工具调用会持续下沉；更耐久的差异化应来自客户系统连接、合规审计、任务恢复、领域评测和标准化部署。

**产品与商业信号**

- SaySo 桌面语音输入和 VUI Agent 均有可访问产品；官网案例覆盖客服、诊断终端和本地生活等场景，但缺少明确客户名与客户侧验证，更接近场景展示。

**主要风险与下一步核验**

## 八、结论摘要

本期经过重新核验后，**严格名单维持 6 家，本周无新增融资、并购或人数跨过 100 的重大变化**。但这不是旧报告的复制：词元无限创始团队与 Mindverse 最新 A 轮得到纠正，VUI 的 Agent/API/工具轨迹与公开计费、GrowthGPT 的收费入口与第三方上架构成新的可验证产品信号。

这些变化仍没有跨越最关键的证据门槛：公开定价不是付款，客户 Logo 不是合同，Stars 不是生产采用，公司自报 ARR/效果也不是可审计收入。下一期最值得追踪的仍是生产可靠性、付费与续费、部署复用、权限审计，以及平台研发相对客户定制的人力占比。
