## 今日 Feature 趋势摘要

1. **“学 AI”正在分成基础、生成式应用和 Agent 三层。** `AI-For-Beginners` 仍强在经典 AI/ML 全景；`generative-ai-for-beginners` 才覆盖 Prompt、Function Calling、RAG 与 Agent。二者同时上榜也提醒用户：课程名相近，不代表内容时代和目标相同。
2. **Skill 从提示词文件继续向专业能力包与地域能力包分化。** `reverse-skill` 把安全任务路由、工具自举、授权和证据交付串联起来；`k-skill` 则把韩国公共数据、文书、出行、金融与语言文化能力封装给 Agent。真正价值不在 Skill 数量，而在依赖、来源、失败降级和宿主兼容是否透明。
3. **Agent 的“可嵌入、可共享、可持续运行”成为产品层竞争点。** Copilot SDK 把完整编码 Agent loop、工具、权限和会话放进应用；DeerFlow 把长任务、子 Agent、沙箱、记忆、浏览器、消息渠道和定时任务聚到一个工作台；两者分别代表 SDK 与成品 harness。
4. **记忆正在从单用户聊天历史变成团队可治理资产。** TencentDB Agent Memory 将对话、Skill、文档和代码图谱分成可分配资产，但当前最新团队版仍是 Beta；“有记忆”不等于跨框架、跨成员、权限与迁移都已成熟。
5. **本地多模态工具的价值集中在“完整工作流”，而非单模型 Demo。** `speech-to-speech` 交付可替换 STT/LLM/TTS 的实时语音后端；Voice-Pro 串联下载、分离、字幕、翻译、TTS 和克隆；TRELLIS.2 从单图生成带 PBR 纹理的 3D 资产。三者都把硬件、模型下载和依赖成本留给用户。
6. **版本页面已不能单独代表真实可用边界。** 今日多个项目存在 PyPI/tag/GitHub Release/main 漂移：`speech-to-speech` 的 PyPI 已到 0.2.11、GitHub Latest 仍是 v0.2.10；Copilot SDK 的稳定版是 1.0.8、1.0.9-preview.2 仍预发布；`reverse-skill` 的 main 比唯一正式版多 27 个提交。

## Feature 深度卡片

### 1. [microsoft/AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners)

**一句话定位：** 面向 AI 初学者和教师，用一套可本地化的课程、Notebook、Lab 与 Quiz 建立从符号 AI、神经网络到 CV、NLP、RL 和经典多智能体的基础地图；它不是 2026 年的 LLM Agent 应用教程。

**典型场景：** 个人系统补基础；高校/企业训练营；PyTorch 与 TensorFlow 对照学习；免安装 Workshop；用小实验判断 CV/NLP/RL 学习方向。

| Feature | 能做什么 → 用户价值 → 适用场景 | 状态 / 边界 |
|---|---|---|
| **12 周 AI 全景课程** | 从符号推理、神经网络、CV、NLP、RL 到伦理建立连续知识地图 → 避免把 AI 等同于 LLM → 自学/概论课 | 教材开箱可读；“24 lessons”与实际目录编号不完全一致 |
| **PyTorch / TensorFlow 双轨 Notebook** | 用两种主流框架练 CNN、RNN、Transformer、VAE/GAN 等 → 可对照迁移概念 → 框架选型/教学 | 多章双实现但并非逐课等价；需 Conda/Jupyter、模型与数据 |
| **读—跑—改—Lab—Quiz** | 把概念、可执行代码、小挑战和部分作业连接起来 → 获得即时反馈 → 自主学习/翻转课堂 | 无统一成绩、进度或自动判题后台；并非每章都有 Lab |
| **4 个 Beginner-Friendly Examples** | 用 NumPy/TensorFlow 快速体验分类、神经网络、图像与情感分析 → 第一小时即可见结果 → 课程开场 | 多数是教学玩具，不是生产模板，[Examples](https://github.com/microsoft/AI-For-Beginners/tree/main/examples) |
| **CV / NLP / 多模态任务链** | 从 OpenCV、CNN、检测/分割到文本表示、RNN/Transformer、CLIP/VQGAN → 看见任务演进 → 方向探索 | LLM/多模态偏 GPT-2/3、CLIP、DALL-E 早期内容，不是最新 API 指南 |
| **符号 AI、遗传算法、RL 与经典 Multi-Agent** | 用规则、搜索、NetLogo 群体模拟和 BDI 补齐非 LLM AI → 扩大方法选择 → AI 概论/模拟 | **Multi-Agent 是经典 agent-based simulation，不是 LLM Agent、MCP 或 agentic workflow** |
| **责任 AI 课程** | 讨论公平、安全、隐私、透明和问责 → 在建模之外建立风险清单 → 学生项目评审 | 原则性入门；不是法规合规、红队或治理平台 |
| **多环境运行** | 支持本地、VS Code、Dev Container、Codespaces、Binder、Colab、Azure Notebook → 按设备/预算选入口 → 课堂/机房 | 入口多不等于全部 Notebook 一键成功；GPU/云资源可能收费，[How to Run](https://github.com/microsoft/AI-For-Beginners/blob/main/lessons/0-course-setup/how-to-run.md) |
| **在线/本地 Quiz 与教师指南** | 提供 quiz app、课堂组织与 GitHub Classroom 建议 → 教师少从零备课 → 训练营/学校 | 文档分别写 40/50 quizzes，不能当稳定规格；本地 app 需 Node |
| **50+ 语言与离线阅读** | 自动同步翻译、Docsify/PDF、稀疏克隆 → 扩大非英语和弱网可达性 → 国际课堂 | 自动翻译不等于人工审校、图片/测验完全本地化 |

**开箱/配置/付费：** 教材、Notebook 源码、在线 Quiz 和 MIT Fork 开箱可用；完整实验需 Python/Jupyter/深度学习依赖、模型/数据下载，重训练最好有 GPU；Codespaces、Azure 与云 GPU 受额度或费用约束。仓库无 Releases/Beta/公开路线图，教学复用应固定 commit。

**同类与易用性：** 相比 `ML-For-Beginners`，本项目覆盖深度学习、CV/NLP/RL；相比 `generative-ai-for-beginners` 和 `ai-agents-for-beginners`，基础面更宽，但缺 RAG、Function Calling、MCP、Computer Use、LLMOps 和现代 Agent。它有 Notebook UI、Quiz、Dev Container、多平台指南与教师材料，却没有产品 CLI/API/SDK、统一学习控制台或应用部署模板。

**限制与今日关注：** README 主动承认部分神经架构不够 SOTA；LLM 章含未经可信公开资料支持的参数量表述，报告不采用；课程/测验数量口径也有冲突。**事实**：仓库仍持续做翻译、依赖和链接维护。**推断**：常青教材、Microsoft 初学者系列品牌与“先补基础再追 Agent”的反向需求，可能共同促成今日 +949。

### 2. [zhaoxuya520/reverse-skill](https://github.com/zhaoxuya520/reverse-skill)

**一句话定位：** 面向 Claude Code、Codex、Cursor、Cline 等代码 Agent 的安全任务 Skill Router，把逆向/授权测试先分到正确手册，再连接本地工具并用 scope、证据链和报告模板形成可复查交付；它本身不是安全模型或托管平台。

**典型场景：** APK/IPA/二进制逆向；JS/API 安全分析；授权红队与 CTF；新分析机工具盘点；团队安全交付和经验沉淀。

| Feature | 能做什么 → 用户价值 → 适用场景 | 状态 / 边界 |
|---|---|---|
| **PRIMARY 路由 + 三轴矩阵** | 按目标、意图、现有工具选主 Skill → 少在工具间盲猜 → 模糊/跨域任务 | v1.0.0 已发；词频加权评分为 main-only Unreleased |
| **安全领域 Playbook** | 为移动、二进制、JS、固件、API、LLM、供应链等给步骤/清单 → 减少阶段遗漏 → 逆向/安全评估 | v1.0.0 有 20+ 模块；main 新增 18 个领域未打 tag |
| **本机 Tool Index** | 扫描路径/版本并生成机器专属索引 → Agent 少编造不存在命令 → 多机迁移 | 需本地刷新；“发现工具”不等于 MCP 已配置 |
| **按需 Bootstrap** | manifest 驱动安装/登记 jadx、Frida、Ghidra、Nmap 等 → 用到再补环境 → 临时实验机 | 外部网络、权限和许可证自备；pin/摘要校验增强主要在 main |
| **Agent / MCP 对接指南** | 给多宿主与 anything-analyzer、IDA、Burp 等配置 → 让 Agent 操作真实工具 → 动态分析 | 需安装/启动外部服务；项目不托管 MCP/模型 |
| **Scope/Auth/Network 门** | `case-init`/`case-guard` 固化授权与范围 → 降低误扫/越权 → 客户项目 | v1.0.0 已有；当前 [#40](https://github.com/zhaoxuya520/reverse-skill/issues/40) 报告 CaseName 路径逃逸 |
| **Evidence→Finding→Path** | 记录观察、命令、hash、结论与攻击路径 → 报告可复现 → 漏洞/逆向交付 | 文本契约可用；不是不可篡改数据库或结论验证器 |
| **Timeline / WorkItems / 角色交接** | 按阶段和角色维护时间线、覆盖清单、handoff → 长任务少丢上下文 → 多人/多 Agent | 是协作协议，不自动启动 Agent、调度队列或解决冲突 |
| **报告与图表模板** | 生成中英 Markdown、复现步骤和 Mermaid/Graphviz → 更快交付 → 审计/CTF writeup | 渲染与内容真实性仍需外部工具和人工复核 |
| **Field Journal** | 将脱敏命令、失败与成功路径回写索引 → 减少重复踩坑 → 团队知识库 | “自动进化”是 Markdown 经验回写，不是在线学习/微调 |

**开箱/配置/付费：** 路由、手册、case/evidence/report/journal 模板克隆即用；PowerShell 路径最完整，实际任务需要代码 Agent、JDK/Node/Python、设备、MCP 和安全工具，IDA Pro/Burp 等可能付费。核心 MIT，CTF 子包 GPLv3，外部工具另计许可。

**同类与易用性：** 相比 `hack-skills`/`Anthropic-Cybersecurity-Skills`，它的差异不是条目最多，而是“本机工具→授权→证据→报告→Journal”闭环；弱在 Web 技能目录、标准 `npx skills add`、统一 API/SDK、独立 runtime/UI 与公开成功率基准。CLI、模板和配置示例丰富，但没有一键托管 Demo。

**限制与今日关注：** 唯一正式版仍是 [v1.0.0](https://github.com/zhaoxuya520/reverse-skill/releases/tag/v1.0.0)，main 超前 27 commits；新增领域、供应链加固、Burp 修复和新评分均不得反推为 v1.0.0。stock macOS Bash 3.2 在 [#38](https://github.com/zhaoxuya520/reverse-skill/issues/38)/[#41](https://github.com/zhaoxuya520/reverse-skill/issues/41) 失败，Kali 未强制 tag/SHA 见 [#39](https://github.com/zhaoxuya520/reverse-skill/issues/39)。**事实**：今日仍在合入安全/路由修复。**推断**：专业安全 Skill、既有 Coding Agent 复用和高密度模板共同推动 +1,320，也暴露了真实用户审计压力。

## 今天最值得体验的 3 个项目

1. **[bytedance/deer-flow](https://github.com/bytedance/deer-flow)**：最适合体验“Agent 工作台而非聊天框”。从 v2.0.0 的 Deep Research + 上传资料 + 子 Agent + Artifact 交付开始，再按需启用 Docker Sandbox 和 IM；若想试 Scheduler、Browser 或 TUI，必须明确使用 `main`/2.1.0 Unreleased，并在本地可信网络验证权限。
2. **[github/copilot-sdk](https://github.com/github/copilot-sdk)**：最适合验证“把现成 Coding Agent 嵌进自己的产品”。建议用稳定 1.0.8 做只读 PoC：streaming + custom tool + permission handler + session resume；BYOK、Remote/Cloud 和 preview Agent Factories 分阶段引入，不要复制 `approve-all` 到生产。
3. **[microsoft/TRELLIS.2](https://github.com/microsoft/TRELLIS.2)**：最适合立即感知 Feature 价值。先在公共 HF Space 用单图测试复杂拓扑、PBR 与 GLB，再决定是否承担 Linux + 24GB NVIDIA 的本地门槛；把输出当可继续修模的 3D 候选，不当扫描级真实或直接生产资产。

选择说明：语音/机器人开发者可将第三项替换为 `speech-to-speech`；韩国市场用户优先试 `k-skill` 的只读公共数据、韩文与 HWP Skills；希望评估团队记忆者可在非敏感数据上试 TencentDB v2 Beta，但应先验证 v1 记忆质量、备份、日志与权限。

## 值得持续跟踪的新 Feature 方向

1. **Feature 级发布 provenance**：同一仓库的 README、PyPI/npm、GitHub Release、tag 和 main 应能自动标出每项 Feature 首次出现在哪个版本，避免“文档已写”被误当“稳定已发”。
2. **团队记忆的资产治理**：记忆、Skill、Wiki、CodeGraph、权限、版本、来源和 Loadout 正在合流；下一步应看审计、删除/迁移、冲突事实、质量评测与跨框架契约，而不是只看召回率。
3. **长运行 Agent 的安全执行面**：Scheduler、Browser、IM、后台任务和子 Agent 越完整，越需要默认 Sandbox、工具审批、网络 allowlist、Secrets 隔离、run ownership、幂等/重试、可恢复事件流与人工接管。
4. **Skill 的地域化与现实交易边界**：`k-skill` 说明本地服务、语言、文件格式和公共数据能形成强差异；下一步应标准化上游健康、ToS/许可、登录/CAPTCHA、支付/提交确认和宿主动作能力矩阵。
5. **从单模型 Demo 到可返工的多模态工作流**：语音的字幕/时轴/分轨/翻译/克隆，3D 的材质/拓扑/GLB/修模，用户价值都来自完整产物流；未来应强化版本化资产、人工 QA、批处理、生产 API 与 provenance。
6. **可嵌入 Agent 的统一产品原语**：强类型事件、工具权限、Hooks、session resume、预算、Remote/Cloud、Artifacts 与观测正成为 SDK 公共层；值得看它们是否形成跨 runtime 的可移植契约。
7. **“本地/开源”逐组件透明度**：项目应分别标明模型、Embedding、搜索、翻译、语音、浏览器、日志和记忆何时出网、计费、持久化或降级；笼统的 local/open-source 标签不足以表达真实成本和隐私边界。
8. **Feature 可复现性而非精选 Demo**：课程要固定模型/数据/依赖，3D/语音要报告消费级硬件端到端数据，Agent 要公开任务成功/失败/人工接管；作者自报 benchmark 和漂亮视频都只能作为方向信号。
