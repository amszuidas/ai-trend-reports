#### 摘要

【文章陈述】蚂蚁 inclusionAI 团队开源 LLaDA2.2-flash，尝试把离散扩散语言模型推进到长程 Agent 任务。该模型为 100B 级 MoE，原生支持 128K 上下文；核心是将 Levenshtein 编辑引入块并行去噪，使模型可对生成序列执行保留、替换、删除和插入，并用 L-EBPO 根据多轮工具交互的环境奖励学习何时纠错。BlockRouting 则限制每个扩散块的专家池，降低长上下文显存与通信开销。团队报告称，七项 Agent 基准均分距自回归 Ling-2.6-flash 不到 2 分，BF16 平均吞吐约为后者 1.64 倍；但结果主要来自团队自测，部分比较采用不同 scaffold。

#### 关键观点与事实

- **【可核验事实】** 官方模型卡确认 LLaDA2.2-flash 为约 100B 非嵌入参数的 MoE 离散扩散模型，支持 128K 上下文，以 Apache-2.0 开放。
- **【团队陈述】** Levenshtein 块扩散让模型同时执行 KEEP、SUBSTITUTE、DELETE、INSERT，L-EBPO 用环境奖励训练多轮编辑策略。
- **【团队自报】** SWE-bench Verified 消融从 35.8 提升至 44.4；七项 Agent 基准均分 53.83，对比 Ling-2.6-flash 的 55.74。
- **【团队自报】** BF16 平均吞吐为对照模型的 1.64 倍，FP8 量化后再提升 18.6%，尚无独立复现。
- **【核验限制】** 官方表格中的部分模型使用 OpenHands，部分使用 Claude Code，不能把分数差异直接解释为纯模型能力差异。

**行业意义：** **【主 Agent 推断】** 该工作把扩散模型的并行生成与 Agent 所需的反复修订、工具反馈结合，为自回归之外的 Agent 架构提供可复现候选。真正影响取决于第三方同条件评测、部署栈成熟度，以及吞吐优势能否转化为端到端时延和成本优势。

#### 摘要

【文章陈述】吴恩达团队推出 OpenWorker，一款本地优先、MIT 开源的桌面 Agent，目标不是继续对话或生成待办清单，而是直接交付研究文档、演示稿、表格、日程与消息等成果。它可访问本地文件和终端，连接 Gmail、Google Calendar、Slack、Notion 等 25 种以上服务，并支持 MCP；模型层不绑定单一厂商，也可连接本地 Ollama。产品将对外发送消息、修改日历和执行 Shell 命令设为审批门槛，任务可定时重复运行。官方仍将其标为开放测试版，Windows 安装包尚未签名；“本地优先”也不意味着数据完全不出设备。

#### 关键观点与事实

- **【可核验事实】** OpenWorker 采用 MIT License，官方标记为 Open Beta；macOS 版本已签名和公证，Windows 构建仍未签名。
- **【可核验事实】** 项目支持 25 个以上连接器、MCP、本地文件和终端，可切换云模型或本地 Ollama。
- **【官方陈述】** Agent 循环、会话、密钥和工作文件保存在本地；OAuth 握手与用户选择的模型、集成是数据外流例外。
- **【可核验事实】** 发送消息、日历变更、Shell 命令等高影响操作设置人工审批点，并支持周期性任务。
- **【核验限制】** 测试版仍需评估权限边界、连接器安全、动作可靠性和失败恢复。

**行业意义：** **【主 Agent 推断】** OpenWorker 把“可改代码的开源 Agent”带到非开发者桌面，并用本地优先、模型可替换和显式审批回应隐私与锁定问题；能否成为日常执行层取决于跨应用动作可靠性和权限治理。

### 【量子位】近百名玩家涌入具身数据：一年融资44.7亿，谁能真靠“卖数据”赚钱？

#### 摘要

【文章陈述】量子位统计国内具身数据赛道 97 家玩家，其中 70 家做数据采集、27 家做基础设施；采集路线涵盖真机遥操作、无本体采集、仿真合成和网络视频蒸馏，43% 的采集方采用多路线组合。文章估算当前行业年产能约 160万—180 万小时，另有 7000万—8000 万条记录，但各公司统计单位不同，无法直接换算。15 家独立数据服务商一年内完成 34 笔融资、合计约 44.7 亿元，其中光轮智能约占七成。独立具身数据服务已形成品类，但企业普遍成立时间短、利润披露不足，规模化需求和可持续商业模式仍未被证明。

#### 关键观点与事实

- **【文章统计】** 97 家玩家中，70 家从事数据采集、27 家提供基础设施；39 家是独立数据服务商。
- **【文章统计】** 70 家采集方中，30 家采用多路线，22 家仅做真机遥操作，15 家仅做无本体采集。
- **【文章统计】** 65 家属于具身原生团队，32 家由其他行业转入；数据工厂分布在 20 个省份，长三角约有 30 座。
- **【文章统计】** 2025-07-01 至 2026-07-01，15 家独立服务商获 34 笔融资、约 44.7 亿元；光轮智能约占 31 亿元。
- **【核验限制】** 产能同时使用“小时”和“条数”，无统一换算；融资高度集中且多数企业未披露利润，不能由融资额推导收入规模。

**行业意义：** **【主 Agent 推断】** 具身数据已从机器人公司的内部能力分化为独立供应链，但资本和供给增长快于商业验证。未来竞争会转向数据有效性、跨本体泛化、交付成本与客户复购，并需要统一质量和计量标准。
