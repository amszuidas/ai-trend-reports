### 【量子位】全球首个Agentic扩散模型来了：边行动边纠错，128K上下文追平自回归

- 作者：鹭羽
- 发布时间：2026-07-28 12:18:15（Asia/Shanghai）
- [原文链接](https://www.qbitai.com/2026/07/461650.html)
- 访问范围：完整正文，无付费墙
- 入选依据：窗口内最新的量子位编辑部技术报道，抓取时位于官网首屏头条；[官方 GitHub](https://github.com/inclusionAI/LLaDA2.X)、[模型卡与权重](https://huggingface.co/inclusionAI/LLaDA2.2-flash)及[技术报告](https://github.com/inclusionAI/LLaDA2.X/blob/main/LLaDA2_2_tech_report.pdf)均公开。抓取时 GitHub 约 455 Star，Hugging Face 约 59 Like、过去一个月 328 次下载；这些是早期可见信号，不代表生产采用。

#### 摘要

【文章陈述】蚂蚁 inclusionAI 团队开源 LLaDA2.2-flash，尝试把离散扩散语言模型推进到长程 Agent 任务。该模型为 100B 级 MoE，原生支持 128K 上下文；核心是将 Levenshtein 编辑引入块并行去噪，使模型可对生成序列执行保留、替换、删除和插入，并用 L-EBPO 根据多轮工具交互的环境奖励学习何时纠错。BlockRouting 则限制每个扩散块的专家池，降低长上下文下的 HBM 与通信开销。团队报告称，其七项 Agent 基准均分距自回归 Ling-2.6-flash 不到 2 分，BF16 平均吞吐约为后者 1.64 倍；但部分对比使用不同 scaffold，不能视为独立、严格同条件的全面追平。

#### 关键观点与事实

- **【可核验事实】** 官方模型卡显示 LLaDA2.2-flash 是 100B 非嵌入参数的 MoE 扩散语言模型，支持 128K 上下文，使用 `DELETE`、`INSERT` 编辑控制 Token，并以 Apache-2.0 发布。
- **【团队自报】** Levenshtein 编辑消融在 SWE-bench Verified 上把得分从 35.8 提升到 44.4，即绝对提升 8.6 个百分点；尚无独立复现。
- **【可核验事实】** 模型卡列出的结果中，LLaDA2.2-flash 在 τ²-Bench、PinchBench、MCP-Atlas 上高于 Ling-2.6-flash，在 SWE-bench 系列、Claw-Eval 和 BFCL-V4 等任务上仍落后。
- **【重要限制】** 模型卡注明部分 Ling 分数使用 OpenHands scaffold，而 LLaDA2.2 的 SWE-bench 系列使用 Claude Code scaffold；跨环境分数不能直接合成严格排名。
- **【核验限制】** 模型卡显示 SGLang 部署支持仍为“即将上线”，公开下载量也处于早期阶段。

**行业意义：** **【主 Agent 推断】** 如果后续独立评测确认质量接近而吞吐更高，扩散语言模型可能成为 Agent 推理的第二条工程路线，尤其适合低延迟、高频工具交互和生成中纠错；近期更现实的形态可能是与自回归模型混合编排。

### 【量子位】陶哲轩在菲尔兹颁奖现场：数学迎来百年新危机

- 作者：一水
- 发布时间：2026-07-27 17:05:21（Asia/Shanghai）
- [原文链接](https://www.qbitai.com/2026/07/461398.html)
- 访问范围：完整正文，无付费墙
- 入选依据：量子位首页靠前文章，承接菲尔兹奖与 ICM 的集中关注；报道附有[陶哲轩 ICM 2026 原始演讲 PDF](https://teorth.github.io/tao-web/slides/age-of-ai-icm-2026.pdf)，可直接核对 First Proof 数据、条件假设和政策主张。官网没有公开稳定互动数字。

#### 摘要

【文章陈述】陶哲轩在 ICM 2026 演讲中提出，数学正从“证明稀缺”走向“证明过剩”，危机不再是逻辑基础，而是数学共同体的价值与实践基础。基于“AI 很快能以合理成本完成相当比例研究级数学任务”的工作假设，他指出，若只把解出问题设为目标，生成、验证、清晰表达、同行吸收与人才培养之间会发生严重的“阻抗失配”。AI 可以批量产生候选证明，Lean 等工具能验证形式正确性，但人类未必理解、愿意审阅或能把成果纳入共同知识。他建议披露 AI 使用，把正确性和引用责任留给人类作者，并提高讲解、评审和正典化工作的价值。

#### 关键观点与事实

- **【可核验事实】** 原始演讲 PDF 显示，First Proof 第二批以 10 道新研究级问题测试 4 套 AI 系统，专家评审认定其中 7 道至少被一支团队以可发表质量解决，单题算力成本约 10—1000 美元。
- **【可核验事实】** 陶哲轩明确把后续讨论设为条件分析，而不是断言最强版本的 AI 能力假设已经成立。
- **【文章陈述】** 他将未来瓶颈概括为“证明消化不良”：证明生成速度可能超过验证、阐释、同行评审和共同体吸收速度。
- **【文章陈述】** 他主张常态化披露 AI 使用，并要求人类作者继续承担正确性、引用和可解释报告的责任。
- **【主 Agent 推断】** 若评价体系仍只奖励“第一个解出”，低质量成果洪流会放大；验证、讲解、整理和知识治理将成为稀缺基础设施。

**行业意义：** **【主 Agent 推断】** AI for Science 产品不能只提高候选答案产量；形式验证、可解释表达、出处追踪、AI 使用披露和人类责任边界，将直接影响科研平台、期刊、大学与资助机构的规则。

#### 关键观点与事实

- **【可核验事实】** NVIDIA 官方 PDF 日期为 2026-07-24，主张开放权重能降低采用门槛、促进竞争、增强用户控制，并支持安全研究与防御。
- **【可核验事实】** 官方名单已超过 70 家机构，包含 AMD、Google、Meta、Microsoft、NVIDIA、OpenAI、Hugging Face 与 Linux Foundation，未列 Anthropic。
- **【文章陈述】** 量子位称相关帖子约有 6000 万次浏览，并引发吴恩达、微软 CEO 纳德拉与 Anthropic 员工等公开讨论；互动数字未独立核验。
- **【文章陈述】** Julian Schrittwieser 的反驳重点不是否定开放模型价值，而是质疑部分公司的开放标准是否一致。
- **【主 Agent 推断】** NVIDIA 支持开放权重兼有生态立场与商业激励：更多自托管模型意味着更分散、持续的推理算力需求；这不自动否定公开信的政策价值。

**行业意义：** **【主 Agent 推断】** 开放权重正从社区议题升级为产业联盟议题。真正有约束力的下一步应是许可证、模型发布、安全响应、评测与政策文本；在此之前，这封公开信的主要作用是划定议程和联盟边界。
