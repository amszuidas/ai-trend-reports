## 今日最重要的趋势

1. **通用 Agent 的竞争已经进入“完整工作系统”阶段。** Latent Space 对 ChatGPT Work 的外部拆解，把隔离计算环境、托管浏览器、上下文边界、权限、自动化、产物与插件放在同一架构中；真正影响大规模使用的不只是模型能力，而是这些系统部件能否安全、连续地协作。
2. **形式验证不等于证明了用户真正提出的命题。** 量子位报道的 Connes 刚性猜想争议表明，Lean 可以验证形式表达内部的推导，却不能自动保证形式化对象、假设与自然语言目标忠实对应。AI 科研需要“机器核验 + 规格审计 + 人类语义复核”。
3. **AI 性能优化越来越依赖软硬件拓扑共同设计。** Latent Space 的公开预览呈现了巨型融合内核与模块化内核之争：NVL72 等特定互连可能让专用 MoE 巨型内核取得峰值收益，而 Rubin 等硬件调度能力又可能降低极端融合的必要性。
4. **算力正在成为高资本开支、强利用率约束的独立生意。** 量子位对 SpaceX 财报的报道把注意力从模型训练移到对外出售算力、长期云合同、电力容量和折旧回收；高速增长的收入与更快增长的前置投入并存，盈利取决于上架速度、出租率和续约质量。
5. **科研 Agent 正从“回答问题”转向可执行、可审计的计算流程。** OpenAI4S 以 Code-as-Action、持续内核、科研 Skills、自有算力接入和不伪造策略串联数据与计算，反映 AI4Science 产品正在把可复现性和错误暴露作为核心能力。

### 【量子位】数学家24小时驳回OpenAI攻破的猜想！“AI证对了每句话，但已跟原猜想无关”

- 作者：梦晨

- 来源：量子位
- [原文链接](https://www.qbitai.com/2026/08/465792.html)
- 访问范围：完整公开正文，无付费墙
- 入选依据／热度信号：首页普通信息流第二张卡；文章直接回应“AI 解决数学难题”的重大主张，并提供反驳稿、OpenAI 说明和 Lean 代码链接。页面未展示公开互动数字。

#### 摘要

【文章陈述】文章称 OpenAI 宣布下一代模型推翻 Connes 刚性猜想后，堪萨斯大学拓扑物理中心的 J. L. Nielsen 逐段追踪其约 3.7 万行 Lean 4 代码，提出两个独立失败路径：AI 构造的关键群不满足猜想要求的 ICC 与 Kazhdan 性质 (T)。因此，即使 Lean 内核确认每一步形式推导成立，所证明的形式陈述也可能没有忠实对应原始数学命题。Nielsen 还给出可编译的 Lean 反驳代码。文章据此强调，证明助手检查内部一致性，不能自动审查规格、对象和自然语言意图是否对齐。

#### 关键观点与事实

- **【文章陈述】** OpenAI 构造两个不同构但生成相同代数的群，并以约 3.7 万行 Lean 代码完成形式验证。
- **【文章陈述】** Nielsen 认为其中一个群既非 ICC，也不具性质 (T)，因此不能构成对原猜想的反例。
- **【文章陈述】** 争议属于“形式命题与目标命题错位”，而非 Lean 内核自身计算错误；Connes 刚性猜想仍然开放。
- **【可核验事实】** 正文提供 [PhilArchive 反驳稿](https://philarchive.org/archive/NIEWTCv17)、[OpenAI 公告](https://openai.com/index/ten-advances-in-mathematics/)和 [公开 Lean 文件](https://github.com/openai/ten-proofs/blob/main/ConnesRigidity.lean)等直接入口；本报告未重新验证数学证明。
- **【主 Agent 推断】** AI 数学系统若只报告“形式验证通过”，容易掩盖定理翻译、对象映射和前提保持的风险，应引入独立规格审计。

**行业意义：** **【主 Agent 推断】** 形式验证是提高科研可靠性的工具，却不能替代语义审查。这类事件会推动高风险科研结论采用“AI 生成证明、机器核验、独立复现、人类语义复核”的分层流程，也会让基准更重视从自然语言到形式规格的忠实度。

【文章公开预览】文章从 Baseten 访谈中“巨型内核已死”的判断切入：跨 GPU 通信和非线性操作使全融合内核难以稳定胜过可独立优化、并行调度的模块化内核，NVIDIA Rubin 的细粒度依赖触发也可能削弱传统融合动机。但 Cursor 随即开源面向 NVL72 的 MoE 训练巨型内核 Mixture-of-Kittens，宣称融合通信与计算后最高快 2.37 倍、整体吞吐提高 41%，把争论转为“巨型内核在哪些工作负载和互连拓扑中值得采用”。其余付费内容不作扩写。

**行业意义：** **【主 Agent 推断】** MoE 训练与推理成本正在推动更强的专用内核和硬件协同设计，但可移植性、上线维护和硬件代际变化仍可能比单项峰值吞吐更重要。采购和部署决策需要观察真实工作负载，而不能只比较单个基准中的最高加速倍数。
