#### 摘要

【文章陈述】这篇月度开放模型盘点认为，训练成本持续上升并未像此前预期那样迅速导致模型实验室合并；能够训练强模型并开放权重的组织反而仍在增加。公开预览重点介绍 Thinking Machines 的多模态 MoE 模型 Inkling、改用 Apache 2.0 的腾讯 Hy3、面向软件工程且强调透明评测的 Poolside Laguna S 2.1，以及 DeepSeek V4 Flash、Kimi K3 等。作者据此判断，开放模型正在性能、效率、部署门槛和授权模式构成的帕累托前沿上扩大实用价值，但商业许可与地缘政策风险也会成为采用时的重要变量。

#### 关键观点与事实

- **【文章陈述】** 作者修正了此前关于行业必然快速整合的判断：尽管训练投入仍可达到数亿美元乃至数十亿美元，训练强模型并开放发布的机构数量仍在增加。
- **【可核验事实】** [Inkling 模型卡](https://huggingface.co/thinkingmachines/Inkling)显示其为 975B 总参数、41B 激活参数的多模态 MoE，可接收文本、图像和音频并输出文本，采用 Apache 2.0。
- **【可核验事实】** 腾讯 [Hy3 模型卡](https://huggingface.co/tencent/Hy3)显示其为 295B-A21B MoE，并采用 Apache 2.0，支持文章关于许可证较前代放宽的描述。
- **【可核验事实】** [Laguna S 2.1 模型卡](https://huggingface.co/poolside/Laguna-S-2.1)显示其为 118B-A8B、百万 Token 上下文模型，采用 OpenMDW-1.1，并公开多项软件工程评测结果。
- **【文章陈述】** 作者将 DeepSeek V4 Flash、Kimi K3 与使用昇腾 910 训练的 LongCat 2.0 并列为生态扩张信号；其性能排名、训练首创性和商业收入判断未在本次全部独立核验。

**行业意义：** **【主 Agent 推断】** 开放模型竞争正从“是否追平最强闭源模型”转向多维选型：单位算力性能、可微调性、本地部署、许可证和评测透明度可能比单一榜单名次更影响采用。多家不同地区、不同规模的机构同时发布强模型，短期更支持生态分散化，而非供给进一步集中。

#### 摘要

【文章陈述】文章介绍华为诺亚方舟实验室开源的 Agent 记忆操作层 MindMemOS。其核心是把记忆从单个 Agent 解耦，用“实体—属性—时间”结构保存当前状态和演化轨迹，并分别通过 MindSchema、Compact Search、Dreaming 和 Feedback 完成领域化提取、多路径检索、离线冲突消解及用户纠错。系统还把真实任务轨迹与 Skill 版本绑定，从成功和失败案例中自动修改 Skill。稿件称其在 LoCoMo、PersonaMem 和 MemoryAgentBench 上取得领先结果，并把 SpreadsheetBench-Verified 成功率提高到 57.2%±2.4%。项目提供 API、SDK、CLI、Skills 和 OpenClaw 插件；完整技术报告仍属即将发布。

#### 关键观点与事实

- **【文章陈述】** 系统以实体、属性、时间组织记忆，保留新旧状态的替代关系，而不只保存文本块或向量片段。
- **【文章陈述】** Dreaming 可归档 19.4%—23.5% 活跃记忆，并将问答准确率最高提升 10.3 个百分点。
- **【文章陈述】** Skill 演进把表格任务成功率从 51.3% 提升到 57.2%，经验来自真实执行轨迹。
- **【可核验事实】** 公开仓库存在且持续更新；抓取时约 597 Stars、60 Forks。README 声明 MIT，但仓库根目录未见独立 `LICENSE` 文件，GitHub API 也未识别许可证。
- **【文章陈述】** 完整技术报告“即将发布”，现阶段不宜把所有基准结果视为已经同行评议或第三方验证。

**行业意义：** **【主 Agent 推断】** Agent 基础设施竞争正在从模型和工具调用延伸到跨应用记忆、反馈学习与 Skill 生命周期。MindMemOS 若能稳定迁移，可把记忆变成用户或组织独立拥有的长期资产；隐私边界、错误记忆传播、评测复现和许可证完整性仍是落地前必须核查的问题。

## 跨来源观察与共识／分歧

- **开放模型的实用价值是本期最明确的跨来源共识。** 量子位的 Qwen3.8 供稿强调开源计划、价格和 Agent 能力，Interconnects 则以 Inkling、Hy3、Laguna、DeepSeek、Kimi 等更广样本说明开放模型供给仍在扩张。两者都把焦点从“能否发布模型”移到“模型能否以合适成本进入真实工作”。
