## 今日最重要的趋势

1. **Agent 的“人在回路”正从逐条点击，迁移到策略、权限和责任设计。** 量子位报道的 Claude Code auto mode 用上下文分类器替代高频人工确认；Founder Park 的招聘 Agent 则把人放在长期项目的目标、权限、审计与最终判断位置。共同点不是移除人，而是把人从容易疲劳的低价值确认中上移。
2. **科研交付物开始从静态 PDF 转向可执行、可审计的证据包。** ARA 试图保存代码、环境、失败路线和主张—证据关系；论文复现与错误检测 Agent 则暴露依赖缺失、结果不符和自动审计误差。两篇文章构成同一事件簇：机器可读性是规模化复现的前提，但机器判定仍不能替代同行复核。
3. **后训练知识正在从实验室经验沉淀为系统化工程学。** Interconnects 把策略梯度、离策略程度、rollout 吞吐、蒸馏和过度优化编排为教材；这说明竞争焦点已从“某个新算法名称”扩展到训练—推理系统、数据管线和评测纪律的协同。
4. **AI 基础设施的资本开支正在被包装成可融资资产。** 量子位转述英伟达与大型金融机构拟搭建独立平台、长期撬动 5000 亿美元第三方资本。若利用率和残值假设成立，资金池会扩大；若需求不及预期，GPU 残值和项目债务可能把 AI 周期风险传导到信用市场。
5. **内容溯源从图片元数据扩展到普通文本。** Claude 隐形标记和 C2PA 元数据代表平台把合规信息嵌入内容本身，但“检出标记”不能证明作者身份，“没有标记”也不能证明由人类生成。可移除性、误判和跨格式兼容性仍是限制。
6. **AI 可能同时压低一般执行岗位需求、抬高关键人才价格。** Founder Park 的招聘对谈将垂直 Agent 的壁垒归于长期上下文、私有数据、合规、Dirty Work 和专业判断；这与“调用更强基础模型就能替代行业软件”的叙事形成差异。

- 可信度提示：实验设计、指标和发布安排为文章转述的 Anthropic 材料；合成攻击集上的漏检率不能直接外推真实流量。

#### 摘要

【文章陈述】Anthropic 将把 Claude Code 新会话默认切换为 auto mode，以分类器逐次判断工具调用风险，分类器额外消耗的 token 不向用户收费；主要云渠道暂时选配。文章称人工权限提示产生严重“确认疲劳”：单条请求拒绝率仅 3%，长会话中识别危险命令的能力继续下降。1053 名测试者实验中，人类拦下 13.6% 的危险提示，auto mode 拦下 89%。系统还加入数据外泄 hard deny、Git 状态和仓库可见性检查；自动分类仍不能消除风险，高风险生产操作需要人工审查。

#### 关键观点与事实

- **【文章陈述】** 单条权限请求有 97% 被用户批准，25% 的交互会话一开始就在 bypass permissions 模式。
- **【文章陈述】** 1053 人实验中，auto mode 拦截率为 89%，人类为 13.6%；超过 50 条提示后，人类拦截率由约 17% 降至约 5%。
- **【文章陈述】** 高严重度生产样本中，人工审批会话的非明确要求有害操作率为 6.3%，auto mode 为 2.4%。
- **【文章陈述】** 加固后的合成攻击集漏检率由 12% 降到 7%；文章同时明确这不是实际流量漏检率。
- **【可核验事实】** 量子位正文公开展示上述数字，并保留 Anthropic 对 auto mode 不能消除风险的提示。

**行业意义：** **【主 Agent 推断】** 开发 Agent 的“人在回路”会从逐条命令确认，迁移到计划审批、组织策略、硬拒绝规则和高风险动作复核。分类器的可解释性、误拦截、版本治理与审计记录将成为企业选型重点。

#### 摘要

【文章陈述】37 名研究者提出 ARA（Agent-Native Research Artifact），主张科研成果不应只以面向人类阅读的 PDF 呈现，而应成为 AI 可直接理解、执行、复现和延伸的知识包。ARA 包含科学逻辑、可执行代码、探索图和证据四层，保存失败路线、环境配置、参数与主张对应的原始证据，以减少传统论文的“叙事税”和“工程税”。团队还提出持续记录过程的 Live Research Manager、把 PDF 与代码仓库转换为 ARA 的编译器，以及机器先做结构检查和复现验证的审稿系统；安全、访问控制和幻觉仍未解决。

#### 关键观点与事实

- **【文章陈述】** PaperBench 的 8921 项专家复现要求中，仅 45.4% 在论文 PDF 中被完整说明。
- **【文章陈述】** 理解测试中 ARA 组准确率为 93.7%，传统 PDF 加代码仓库组为 72.4%。
- **【文章陈述】** 失败路线问题上，两组准确率分别为 81.4% 和 15.7%。
- **【文章陈述】** 15 篇论文、150 项复现任务中，难度加权成功率为 64.4% 对 57.4%；开放式研究延伸并非全面胜出。
- **【可核验事实】** 量子位正文确实给出 ARA 四层结构、配套工具与上述实验数字；本报告未独立复现实验。

- 四个来源分别由四个独立来源 Subagent 调研，每个 Subagent 只负责一个来源，并实际打开候选正文或公开预览；主 Agent 再按时间边界、来源归属、正文完整度、证据强度和上期归档进行复核、去重与分类。

- 文章陈述、可核验事实、媒体转述和主 Agent 推断分层标注。研究实验、公司计划、融资目标、设备残值、招聘薪酬和检测能力不会因为出现在媒体正文中就自动成为独立事实。
