#### 摘要

【文章陈述】文章围绕萝卜快跑进入右舵左行市场展开：香港运输署批准其在机场岛开展车内不设后备操作员、由远程操作员监控的道路测试；Apollo Go 与 Lyft 旗下 Freenow 又在伦敦布伦特区启动配有安全操作员的 RT6 测试。文章认为，右舵适配并非镜像道路规则，而涉及环岛、公交车道、让行方式和临停习惯等“交通语义”迁移。【主 Agent 核验】两地均仍处测试阶段，香港的车内无人和伦敦的车内安全员也不能混写为相同等级的商业运营。

#### 关键观点与事实

- **【可核验事实】** [香港政府 7 月 23 日公告](https://www.info.gov.hk/gia/general/202607/23/P2026072300215.htm?fontSize=1)确认机场岛获准开展无车内后备操作员的无人化测试，并由远程中心监控。
- **【可核验事实】** [Freenow 官方公告](https://www.free-now.com/uk/press/freenow-by-lyft-and-baidu-s-apollo-go-start-autonomous-vehicle-testing-in-london-with-the-rt6-vehicles/)确认 7 月 28 日在伦敦布伦特区开始 RT6 测试，初期车辆仍配安全操作员。
- **【文章陈述】** 这是全球首次在右舵左行交通体系开展全无人测试；香港政府称其为本地无人化里程碑，但未直接为“全球首次”背书。
- **【公司陈述】** Freenow 与 Apollo Go 计划在 2027 年开始向伦敦公众提供乘坐服务，仍取决于后续测试和监管批准。
- **【主 Agent 推断】** 伦敦可能提供更接近的中美 Robotaxi 对照环境，但车队规模、运行区域和监管条件不同，不能简单比较胜负。

**行业意义：** **【主 Agent 推断】** 自动驾驶竞争正从本土技术可行性转向跨法规、跨驾驶文化和跨运营伙伴的复制能力；香港与伦敦不同的安全边界也显示，国际化速度将由监管信任与本地运营能力共同决定。

## 跨来源观察与共识／分歧

- **三种场景形成同一 Agent 工程共识。** Latent Space 的金融案例要求来源、对账、权限与仿真评测；量子位的游戏原型依赖评委 Agent 和人工纠偏；Founder Park 的企业 Coding 强调业务上下文和交付结果。三者共同说明，模型只是系统的一层，harness、环境和验收机制决定可用性。
- **“自我改进”有两种口径，不能混为一谈。** 翁荔报道指向可能改变后继模型或训练流程的 RSI；游戏案例展示的是固定模型在外部工作流中持续返工。前者涉及模型与研发系统演进，后者主要是 harness 优化。
- **企业落地路径存在明显张力。** 金融行业需要标准化治理、持续评测和审计；Founder Park 的 FDE 路径强调深入现场、按结果交付。定制化有助于早期验证价值，但规模化要求把现场经验产品化。
