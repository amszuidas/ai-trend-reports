#### 摘要

【文章陈述】文章采访 Lovable CTO Fabian Hedin，描述公司从 AI 应用生成器向 Agent 平台扩展。Lovable 所谓 capability，是应用中可由 Agent 直接调用的功能；平台通过托管 MCP server 暴露选定能力，使同一应用同时具有传统 UI 和 Agent 接口。“Company brain”希望统一上下文、工具和异步任务，但 Hedin 认为真正难点不是编排，而是能力是否可靠、权限是否正确。连接器在服务端保管加密凭据，以短期密钥和源系统权限执行，避免生成应用直接接触凭据，并为后台任务保留明确的管理员控制边界。

- **【文章陈述】** Hedin 认为，Agent 编排相对容易，正确、可靠且具备权限边界的连接能力才是难点。

**行业意义：** 【主 Agent 推断】SaaS 的竞争接口正在从网页 UI 转向机器可调用的 capability。未来护城河可能不再只是页面和流程，而是可被 Agent 安全发现与组合的工具契约、身份传递、权限图和可观测可靠性。

#### 【Latent Space】“We have foundation models for language, not for physics” — Anima Anandkumar

**中文译名：** 我们有语言基础模型，却还没有物理基础模型

#### 摘要

【文章陈述】Anima Anandkumar 认为，物理世界模型不能直接复制语言模型的 token 扩展路线：科学数据通常只有数万至数十万样本，而高分辨率多尺度系统可能对应数千亿乃至万亿级上下文。她主张把物理结构和归纳偏置写进模型，以 Neural Operator 学习函数空间之间的映射；FourCastNet 则把傅里叶／球谐结构用于全球天气预测。她的长期目标是跨天气、流体与聚变等现象、同时具备模拟和设计能力的“物理基础模型”。

#### 关键观点与事实

- **【文章陈述】** 工业尺度物理系统不能只靠加长 Transformer 上下文；进展依赖结构化建模、物理先验和适合连续系统的算子。
- **【可核验事实】** [FourCastNet 论文](https://arxiv.org/abs/2202.11214)报告其在短期大尺度变量上匹配 ECMWF IFS，并在降水等细粒度变量上表现更好；一周预测可在数秒内生成。
- **【可核验事实】** [Neural Operator 论文](https://arxiv.org/abs/2108.08481)将网络推广为函数空间之间的映射，并强调离散化不变性，可作为 PDE 解算子的代理模型。
- **【文章陈述】** 聚变场景中数千样本即可预测等离子体扰动，并可比传统模拟快约百万倍；本轮未独立复现该数值。
- **【可核验事实】** Caltech 已公布 Anandkumar [获任联合国科学咨询委员会成员](https://www.caltech.edu/about/news/anima-anandkumar-appointed-to-un-scientific-advisory-board)。

**行业意义：** 【主 Agent 推断】Scientific AI 的下一轮竞争未必由参数量主导，而可能取决于能否把对称性、守恒律、几何结构和形式化验证嵌入网络；其算力需求也会偏向高维连续状态、长期稳定 rollout 和可验证控制。

【文章陈述】Skild AI 的 S1 将机器人任务视频作为上下文提示：不微调、不改变权重，单一策略看一次示范后执行此前未见任务，展示煎饼、手冲咖啡、植物换盆和套件组装，最长约 10 分钟。量子位梳理其受控实验：在 10 万小时训练规模下，未见任务平均逐步成功率为 66%，语言提示 VLA 为 9%；单次示范的表现约相当于传统策略接受 380 次后训练演示。Skild 官方博客确认这些数字，但评测来自内部任务集，并允许人工干预从失败中恢复，以保证所有步骤都被计分。

#### 关键观点与事实

- **【可核验事实】** [Skild 官方 S1 博客](https://www.skild.ai/blogs/s1)称任务由单个视频提示指定，同一套权重完成未见任务，无微调或后训练，最长任务约 10 分钟。
- **【可核验事实】** 官方内部实验报告：10 万小时规模下，未见任务逐步成功率 ICL 为 66%，语言提示策略为 9%。
- **【可核验事实】** 植物换盆案例从录完示范到机器人自主执行相隔 11 分钟；单次 ICL 表现约对应 380 个后训练 episode。
- **【可核验事实／限制】** 以上均为 Skild 内部基准，评估中允许人工恢复失败后继续为后续步骤计分。
- **【主 Agent 推断】** 若视频上下文学习能跨实验室和机器人本体复现，新技能部署成本可能从采集数百次真机数据转向录制少量示范。

**行业意义：** S1 把大模型的 in-context learning 范式推向机器人长程操作，核心价值是缩短新技能上线周期；当前证据仍不足以证明“机器人 GPT 时刻”已经到来。

## 跨来源观察：共识与分歧

- **共识：单一模型指标不足以解释产品竞争力。** 量子位的 GLM-5.3、S1 和 Agnes 报道分别落到部署硬件、数据与提示方式、完整生产流程；Latent Space 则强调模型分发平台、推理芯片、Harness 和 SaaS capability。共同方向是把模型放回完整系统衡量。
