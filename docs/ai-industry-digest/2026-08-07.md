#### 摘要

【文章陈述】Founder Park 整理了 AGI Playground 2026 新加坡站的一场企业 Agent 圆桌，邀请 WIZ.AI、Ateve、易点天下 zMaticoo 与 Airwallex 的负责人，从语音客服、Agent 搜索、数字营销和金融执行四类场景讨论生产落地。共同判断是：竞争重点已从“模型看起来多聪明”转向端到端闭环、真实企业上下文、可靠性、成本、权限和审计。语音 Agent 要把首响压到两秒内并对标人工解决率；营销 Agent 需标准化工具和数据入口；支付等不可逆操作必须保留确认、追踪与责任边界。嘉宾对 Token 成本是否会随模型降价而弱化仍有分歧。

#### 关键观点与事实

- **【文章陈述】** 四位嘉宾给出的共同生产门槛是进入真实流程、连接真实数据、无需持续人工盯守，并使全流程成本低于所替代的人工或旧流程。

#### 摘要

【文章陈述／厂商授权稿】蚂蚁集团开源多智能体协作基础设施 Avernet，首个社区版本聚焦“协作网络”：让不同智能体能被发现、被邀请、参与任务并返回结果，同时支持多方共识、过程观测与经验沉淀。文章把问题定义为企业内的组织协作，而不是继续追求掌握全部数据和权限的“超级智能体”；在隐私、合规和业务边界下，每个智能体都需要明确身份、权限与责任。当前版本已开放部分认证、授权、权限控制、生命周期和安全能力，后续计划补齐审计、评测、记忆优化与容器集群支持。覆盖板块和完成率数据未获第三方验证。

#### 关键观点与事实

- **【文章陈述】** Avernet 试图解决智能体之间“找不到、对不齐、跑不快、留不住”四类协作问题，强调发现、共识、流转和经验复用。
- **【可核验事实】** 项目宣布采用 Apache 2.0 协议开源，社区版不绑定单一模型或智能体引擎。
- **【文章陈述】** 首版开放部分身份认证、授权、权限控制、生命周期管理与安全防护能力；审计、可观测评测和记忆优化仍在路线图中。
- **【文章陈述／厂商口径】** 截至 2026 年 7 月 31 日，相关能力覆盖蚂蚁 12 个核心业务板块，任务完成率稳定超过 90%；文章未提供统计口径、样本量和第三方验证。
- **【主 Agent 推断】** Avernet 更像 Agent 组织层／控制平面而不是新模型，生产价值取决于审计、评测、故障隔离与异构系统接入能否按路线图兑现。

**行业意义：** **【主 Agent 推断】** 企业 Agent 正从单体能力演示转向多主体协作与治理。身份、权限、责任、观测和知识沉淀被放到模型能力之前，说明基础设施竞争正在转向“能否在组织边界内可靠完成任务”。

#### 摘要

【文章陈述／厂商授权稿】阿里巴巴视频生成模型 Wan 3.0 开启公测，单次生成时长提升到 30 秒，并加入智能时长推荐、全能参考和更强视频编辑。其差异点是把输入从文本、图片、音频和视频扩展到 doc、xls、ppt、pdf、md 等文档格式，目标是直接把课件、产品材料和业务汇报转换为视频。文章称模型增强了角色、道具、声音、空间关系与风格一致性，也支持修改画面、剧情和台词，但明确承认声音质感与文字准确度仍需改进。公测覆盖多个阿里系入口，并按分辨率公开 API 单价。

#### 关键观点与事实

- **【文章陈述】** Wan 3.0 单次可生成 30 秒视频，并可依据提示词推荐合适时长。
- **【可核验事实】** 公测说明列出 doc、xls、ppt、pdf、md 输入，单文件或链接不超过 100MB、50 页，并公布多端入口。
- **【文章陈述】** 模型可在全能参考任务中保持角色、道具、声音、空间关系与风格，也能编辑画面、剧情和台词。
- **【可核验事实／厂商定价】** 480P、720P、1080P API 定价分别为每秒 0.3、0.6、1.2 元；价格可核验，但不代表最终任务成本或效果。
- **【文章陈述】** 当前声音质感和文字准确度仍有提升空间，授权稿未给出独立评测。

**行业意义：** **【主 Agent 推断】** 视频模型正在从“生成短镜头”迁移为读取业务资料并完成表达任务的生产工具。真正决定采用率的将不只是画质，还包括文档解析保真、图表与品牌元素一致性、编辑能力以及全流程成本。

## 跨来源观察与共识／分歧

- **Founder Park 与量子位的 Avernet 稿形成当日最强共识：企业 Agent 的瓶颈正在上移。** 前者从语音、搜索、营销和金融实践总结可靠性、权限、成本与责任，后者从开源基础设施强调身份、授权、协作、观测和经验沉淀；两者共同指向 Agent 控制平面。
