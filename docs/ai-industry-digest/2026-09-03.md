## 跨来源观察：共识与分歧

- **共识：模型的外层条件正在决定有效价格。** Muse Spark 把折扣和训练数据授权关联；Claude 的缓存价格还要同输出长度一起计算；Qwen 的榜单和 API 宣传也需要放进实际工作流评测。
- **共识：数据生产和数据采集都是能力边界。** OmniTable 处理训练数据的血缘与异常隔离，TwinDex 则尝试降低具身数据从人到机器的对齐损失。两者都把瓶颈从单一模型权重移到数据系统。
- **分歧：机器人产品的成功标准不同。** TwinDex 先看可重复操作、跨任务成功率和故障率；Mirumi 首先要验证情感体验、渠道与付费。前者追求自动化，后者是消费品设计。
