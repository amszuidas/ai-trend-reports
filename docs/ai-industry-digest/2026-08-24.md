- 作者：Dan McAteer

#### 摘要

【文章陈述】文章把 Agent Harness 定义为模型权重之外的环境、工具、上下文、记忆、权限和护栏，并分为三个阶段：早期以外接脚手架弥补模型能力；推理模型出现后，模型与 Harness 开始共同训练；未来外部系统的重点将从“帮助模型操作电脑”转向“管理人的注意力”，决定何时打扰、何时继续以及哪些动作必须审批。作者认为工具使用、压缩和部分编排可被模型吸收，但权限、身份、信任和可理解性不会简单消失。

#### 关键观点与事实

- **【文章陈述】** 演进循环可概括为 `train → absorb → shed → repeat`：模型吸收稳定能力，Harness 删除过时脚手架。
- **【可核验事实】** 原文引用 Harness-Bench：同一模型在不同 Harness、同一组 106 个任务上的得分从 52.4 到 76.2，相差 23.8 分。
- **【作者预测】** Agent 公司可能像提供 `AGENTS.md` 一样提供“人类注意力策略界面”；这不是已实现行业标准。
- **【主 Agent 推断】** 权限、审批、可观察性和中断策略会成为 Agent 平台核心能力，而非附属 UI。

**行业意义：** 模型升级并不会自动抹平系统差异；团队需要同时评估模型能力、运行环境和人机边界，否则“换更强模型”仍可能在权限与长任务交接上失败。

#### 摘要

【文章陈述】`/wayfinder` 面向终态不清、无法一次规划完成的项目。它把工作拆成 grilling、prototype、research 和 human task 等 ticket，由多个子会话分别处理，再通过中央 map 汇总已做决定，让每个子会话既看见必要全局状态，又只承担一个边界清楚的任务。Matt Pocock 认为 Skill 的本质是管理上下文与信息流，关键不是堆提示词，而是让 map、ticket、session 等实体拥有稳定、一致的术语。

#### 关键观点与事实

- **【文章陈述】** 核心结构是 `map + ticket + session`，用于降低长规划中的上下文与 handoff 成本。
- **【文章陈述】** 路径清楚的小功能适合直接询问；只有路线仍处于迷雾中的项目才需要 `/wayfinder`。
- **【受访者观点】** 精确统一的“leading words”可减少 Agent 对同一实体的概念漂移。
- **【主 Agent 推断】** Skills 正从提示词模板转为轻量编排协议，其价值在状态压缩和明确交接，而非神秘自治。

**行业意义：** 长任务可靠性可以通过信息架构改善。显式的人类任务、决策地图和单一职责 ticket，比无限延长上下文更容易审计和恢复。

#### 【量子位】闭源 RSI 的严父：18 个 Agent 自主科研，Kimi K3 靠 Harness 逼近 Opus 5

- 作者：henry
- 发布时间：2026-08-20 17:46:23（Asia/Shanghai）
- [原文链接](https://www.qbitai.com/2026/08/476199.html)；[Prime Intellect 原始研究](https://www.primeintellect.ai/blog/measuring-autonomous-research)
- 访问范围：完整公开正文；原始实验页公开
- 入选依据／热度信号：位于量子位热门文章；Prime Intellect 公布了完整榜单、实验方法、预算、轨迹和 Harness，证据可审计。

#### 摘要

【文章陈述】报道解读 Prime Intellect 对 18 个前沿模型进行的 nanoGPT 优化器速通实验：153 次自主运行、每次 8 张 H200，最长 8.7 天。Kimi K3 配合 Prime Agent 得到 2,930 步，接近 Opus 5 的 2,920 步；Fable 5 为 2,726 步。原始研究同时承认，没有一次运行提出根本性新方法，结果受随机性影响，也不能外推到真实大模型训练。文章因此更适合证明 Harness、复测、消融和实验吞吐的重要性，而非证明 RSI 已实现。

#### 关键观点与事实

- **【可核验事实】** Prime Intellect 原始页确认 153 次运行、18 个模型、8×H200 与最长 8.7 天的设置。
- **【可核验事实】** Kimi K3 + Prime Agent 为 2,930 步，Opus 5 为 2,920，Fable 5 为 2,726；这是单一任务、特定 Harness 下的结果。
- **【可核验事实】** 研究明确称没有运行产生根本性新方法，且基准方差较大。
- **【主 Agent 推断】** Harness 能让较低成本模型在反馈明确的任务中追近强模型，但不能证明通用科研能力等价。

**行业意义：** 自动研发的评估单位应是“模型+Harness+状态+预算+验证规则”。公开轨迹和失败结论，比只公布一个最佳分数更有助于行业判断可复现进步。
