#### 摘要

【文章陈述】量子位援引 SemiAnalysis 的实验室验证报道 OpenAI 首代自研推理 ASIC“Jalapeño”：700W 工程样品在 GPT-OSS、DeepSeek R1 与 Kimi K2.5 的单 Token 预测中，呈现高于 Blackwell 的每瓦吞吐和更低时延。限制同样重要：数据由 OpenAI 提供，SemiAnalysis 只现场核验了部分 InferenceX，尚未运行更贴近长上下文、多轮负载的 AgentX；且 HBM4 Rubin 才是更公平的代际对手。芯片预计 2027 年爬坡量产，工程样品成绩尚不能代表大规模生产表现。

#### 关键观点与事实

- **【文章陈述】** Jalapeño A0 工程样品 TDP 为 700W；报道给出的相对 GB200／GB300 每千瓦推理吞吐优势为 1.5—1.9 倍，端到端时延优势为 1.7—3.6 倍。
- **【文章陈述】** 测试使用 GPT-OSS 120B、DeepSeek R1 670B 与 Kimi K2.5；部分低并发结果约为 1,400 token/s/user，且未启用多 Token 预测、推测解码或 prefill/decode 分离。
- **【可核验事实】** SemiAnalysis 公开预览确认团队在 OpenAI 实验室与工程师运行 InferenceX，同时明确：数字由 OpenAI 提供、未跑完整套件、尚无 AgentX 结果。
- **【文章陈述】** B0 版本据称还可提高约 25% 每瓦性能，量产计划在 2027 年逐步爬坡；部分芯片设计与内核优化使用 Codex 辅助。
- **【主 Agent 推断】** 若长上下文、Agent 负载和大规模集群能复现这些结果，垂直协同会增强 OpenAI 的供应选择和议价能力；短期并不等于训练 GPU 或 CUDA 生态被全面替代。

**行业意义：** 模型公司开始把推理效率问题直接推进到自研硅片和机架系统。不过，真正决定竞争格局的是可比基准、生产良率、软件成熟度、集群可靠性与 2027 年供给，而不是一次工程样品跑分。

- 入选依据／热度信号：本窗口唯一能由 Founder Park 官方全文确认的新稿；[AI Reading Hub 公开索引](https://www.aireadinghub.com/article/16461)将其列为“推荐文章”并显示评分 7。原文未展示阅读量、点赞量或评论量；价值判断主要依据时效、两家实验室的代表性和持续学习对 Agent 能力演进的影响。

#### 摘要

【文章陈述】文章以 AMI Labs 林敏与 Mind Lab Andrew Chen 的对谈为主线，讨论 Agent 为何积累大量交互后，仍不能自动把经验写回能力。双方都把记忆视为从外部存储到参数化学习的连续谱，但路线分歧鲜明：林敏主张用世界模型吸收成功、失败乃至无标签轨迹，通过状态转移学习环境因果；Andrew 更重视 LoRA 和策略模型，把不同能力隔离进适配器，并以路由和多模型协作扩展智能。两人共同承认灾难性遗忘、实时参数更新和训练基础设施仍未解决；关于一年内自训、自评和自主实验的判断属于预测，不是既成事实。

#### 关键观点与事实

- **【文章陈述】** 当前 Agent 的短期记忆主要留在上下文，长期能力通常要等后续训练才能写入权重；用户交互到能力增长之间仍有断层。
- **【受访者观点】** 林敏把 KV Cache、LoRA、世界模型状态等视为不同频率、不同更新与检索成本的记忆载体，认为短期与长期记忆的硬边界应逐步消除。
- **【受访者分歧】** 林敏强调用失败和无标签轨迹学习行动后果；Andrew 更相信编码 Agent、LoRA 与策略学习能筛选轨迹并参数化经验。
- **【可核验事实】** [AMI Labs 官方页](https://amilabs.xyz/)列出 Yann LeCun、Min Lin，并说明以 action-conditioned world models 预测行动后果；[Macaron-V1 论文页](https://huggingface.co/papers/2608.09819)与 [Mixture-of-LoRA Harness](https://github.com/MindLab-Research/Mixture-of-LoRA-Harness)均公开可查。
- **【主 Agent 推断】** 世界模型与 Mixture-of-LoRA 短期更可能组合而非互斥；对“Agent 自我进化”产品仍应要求更新机制、遗忘测试、版本回滚和安全边界证据。

**行业意义：** Agent 竞争将从“上下文能放多少”继续转向经验筛选、在线／增量训练、适配器路由、评测合同与可回滚更新。交互数据丰富本身不等于模型已经获得可复用能力。

- **【文章陈述】** 产品支持飞书企业账号登录、手机远程安排／验收和云电脑后台执行；本次未找到系统性基准或失败率数据来独立验证稳定性。

## 跨来源观察：共识与分歧

- **共识：模型能力之外的系统资产越来越重要。** Founder Park 把持续学习拆成轨迹、世界模型、适配器和训练基础设施；量子位三篇则分别指向芯片／编译栈、企业身份／权限和视觉生成—编辑工具链。共同信号是，单次模型输出已不足以定义产品壁垒。
- **共识：可验证材料必须与宣传性结论分开。** OpenAI 芯片有现场核验但基准不完整；SenseNova 有权重和代码但“比肩”仍缺独立复现；豆包工作有公开产品和媒体实测但没有系统性失败率；持续学习对谈中的百万级 LoRA 与一年期预测也不是既成事实。
- **分歧：Agent“记住并继续工作”有不同技术层次。** Founder Park 关注把经验写回参数或世界模型，豆包工作关注利用现有企业数据与权限继续任务。后者能较快形成产品价值，前者决定 Agent 能否真正从经验中获得新能力。
