## 今日最重要的趋势

1. **模型自我改进正在从“调工具”深入到训练数据生产。** BigBang-V1 把出题、求解、验证与训练后反馈串成闭环，试图让模型持续制造对自己有效的新数据；真正的门槛将是第三方复现、数据污染控制和外循环评价，而不只是生成更多合成样本。
2. **复杂 Coding Agent 项目的核心资产逐渐变成规格、架构和自动验收。** 3D 游戏案例表明，模块边界、并行分工、共享约束和截图质检比“一条提示词”更能解释成品质量；所谓模型成本优势必须在相同质量、人工投入和计费口径下比较。
3. **AI 成本叙事仍缺乏统一口径。** 6.9 亿 token／423 美元与“5 美元复刻”均来自开发者自报，后者还是订阅额度折算而非独立 API 账单，且成品质量不等；标题式倍数不能当作模型经济性的严格基准。
4. **头部 AI 实验室的人事变化已成为战略信号，也更容易被传闻放大。** 关于 Demis Hassabis 交接管理权乃至离职的报道基于匿名消息，而 Google DeepMind 官方页面仍把他列为 CEO；在正式公告前，只能把它视为值得跟踪的组织风险线索。
5. **今日证据呈明显“单一来源、不同强度”分布。** 四个来源中只有量子位更新，三篇又分别依赖团队基准、开发者自报和匿名消息；本期可以提炼议题，但不能把它们写成跨来源共识或已确定的行业事实。

- 作者：闻乐

- 来源：量子位
- [原文链接](https://www.qbitai.com/2026/08/468782.html)
- 访问范围：完整公开正文，无付费墙
- 入选依据／热度信号：本窗口最新文章、官方 Feed 首项、首页文章列表首位；项目提供[公开 GitHub 仓库](https://github.com/endless-frontier/BigBang-v1)，主 Agent 复核时为 43 stars、4 forks。量子位页面未展示阅读量或评论量，未作估算。

#### 摘要

【文章陈述】文章介绍上海交大人工智能学院、深势科技与上海算法创新研究院相关团队推出的 BigBang-V1。其“数据层 RSI”不是只让模型调用工具，而是由 Generator Agent 生成并求解科学任务、Critic Agent 审核候选数据，再用真实训练后的留出任务表现反向校准两者。团队称该模型总参数 35B、推理激活约 3B、上下文 262K，后训练数据全部由 AI 合成，并在长程搜索、编程和科研评测上取得多项同规模领先。人类仍负责目标、预算、风险边界和最终验收。

#### 关键观点与事实

- **【文章陈述】** BigBang-V1 被报道为以 recursive self-improving 方式训练的基座模型，AI 参与出题、求解、验证和数据策略调整。
- **【可核验事实】** [项目仓库](https://github.com/endless-frontier/BigBang-v1)确认模型基于 Qwen3.6-35B-A3B，总参数 35B、激活参数 3B，并公开部分评测脚本与轻量 Agent harness；论文尚标记为“Coming Soon”。
- **【团队自报、未独立复现】** 仓库称其在所选 8 项代表性基准的 35B 模型比较中均为最高，并报告 BrowseComp 76.5、SWE-Bench Pro 54.2。文章“10 项第一”与仓库当前“8 项代表性基准”口径不同，不能混为独立结论。
- **【文章陈述】** Generator／Critic 内循环之外，系统以训练后的留出任务成绩构成外循环，试图避免生成器只迎合评分器。
- **【可核验事实】** 仓库公开了检索污染限制与不同 benchmark harness 说明；这提高可审查性，但不等于第三方已复现全部成绩。

**行业意义：** **【主 Agent 推断】** 若结果可复现，竞争重点可能从静态数据规模转向“能持续生成、验证并证明训练有效的数据生产系统”，推动科研 Agent、合成数据工程和后训练进一步融合。现阶段不应把“35B 超越 1.6T”等选择性结果泛化到所有任务。

#### 摘要

【文章陈述】文章对比两组用前沿模型生成 3D 水上竞速游戏的实验。Vyom 称用 Opus 5 和约 2000 字提示词生成《INK TIDE》，消耗 6.9 亿 token、约 423 美元；提示词先定义共享架构，再把水面、物理、渲染、AI 和 UI 拆给子 Agent，并用截图 harness 质检。另一名开发者称在 Codex 中用 GPT-5.6 Sol Ultra 调度、Luna Max 执行，以两条提示词、约 5 小时完成相似版本，额度折算约 5 美元。文章也承认两者质量和计费口径并不相同。

#### 关键观点与事实

- **【可核验事实】** [Wave-Racer 仓库](https://github.com/Vyom-26/Wave-Racer)显示项目采用 Vite、TypeScript、Three.js，模型、纹理与声音均由代码生成，并提供 Playwright 截图 harness。
- **【可核验事实】** 仓库将共享海浪场、调色板、架构契约和性能预算写成明确约束，说明成品依赖系统设计而不只是一次生成。
- **【文章陈述、未独立核验】** 6.9 亿 token、423 美元、“单提示词”，以及复刻版约 5 小时、两条提示词、折算 5 美元，均来自开发者帖子。
- **【文章明确限定】** “5 美元”是订阅套餐额度折算，不是独立 API 账单；复刻版的视觉细节和总体完成度也低于原作。
- **【可核验事实】** 量子位参考链接写成 `Vyom-26/Wave-Racer3`，主 Agent 复核时返回 404；可访问的实际仓库是 `Vyom-26/Wave-Racer`。

**行业意义：** **【主 Agent 推断】** 复杂 Agent 项目的生产力来自清晰规格、模块所有权、共享约束和可重复验收。该案例不能证明某模型便宜约 80 倍；只有统一质量目标、人工投入、硬件和 API 计费口径后，成本比较才有意义。
