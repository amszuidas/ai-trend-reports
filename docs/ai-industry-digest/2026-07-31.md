- 发布时间：2026-07-30 14:14:43（Asia/Shanghai）

#### 摘要

【文章陈述】文章解读无问芯穹的跨数据中心异构推理架构 PDD：在传统 Prefill—Decode 分离之间加入同机房 RelayDecode，让本地中继先输出 Token，以掩盖 KV Cache 通过广域网传往远端 MainDecode 的延迟；交接时只传 Token ID，由远端重算增量 KV Cache。配合 Decode 端 Radix Cache，系统利用 Agent 负载“长上下文、高前缀命中、短输出”的特征，把异构硬件用于各自更擅长的阶段。项目方测试中，P90 首 Token 延迟由 18.3 秒降至 9.8 秒，单位成本下的 SLA 有效吞吐性价比提高 37.5%。

#### 关键观点与事实

- **【可核验事实】** [PDD 技术仓库](https://github.com/infinigence/pdd)说明其由 Prefill、RelayDecode、MainDecode 三层组成，RLD 先行解码，远端 MD 收到 KV Cache 后接棒。
- **【项目方结果】** Decode-side Radix Cache 在平均 90% 前缀命中率下，可把跨数据中心带宽需求最多降低 10 倍。
- **【项目方结果】** Extend-Decode Handoff 只传 Token ID、由 MD 重算增量 KV Cache；每 100 Token 的负载从 4,649KB 缩至 1.5KB。
- **【项目方结果】** DeepSeek‑V4‑pro 和真实 Agent 负载轨迹测试中，P90 TTFT 下降 46%；相对同机房同构基线，RPS 提高 27.8%、总成本降低 3.5%–7.1%、Benefit-Cost Ratio 提高 37.5%。
- **【主 Agent 核验】** 标题“成本直降近 40%”容易误读；37.5% 对应单位成本的 SLA 吞吐性价比提升，并非账面总成本下降近 40%。结果来自项目团队，尚无独立第三方复现。

**行业意义：** **【主 Agent 推断】** PDD 为分散、异构、网络条件不理想的存量 GPU 集群提供了 MaaS 架构候选。其普适性仍需在更多模型、网络波动、低缓存命中和故障条件下验证。

#### 摘要

【文章陈述】文章整理 Boris Cherny 的产品方法：模型迭代速度快于 Harness，应定期删除旧提示词、Skills、Hooks，再通过消融实验逐项加回仍然有效的约束，而不是把旧模型经验固化为永久规则。他以“Product Overhang”描述模型能力超出既有产品边界，并主张用更难任务、开放实验和可自我验证的执行环境给模型“解缚”。长时运行 Agent 的关键不是堆提示词，而是明确目标、边界和退出条件，并让模型持续验证产出；安全、权限与静态分析仍是必须保留的 Harness 层。

#### 关键观点与事实

- **【文章陈述】** Boris 建议约每六个月重新审视甚至删除 Claude.md、Skills、Hooks 和系统提示词，再用逐行消融测试判断哪些约束有效。
- **【文章陈述】** 随模型能力提升，Claude Code 的 Harness 越来越集中于安全、权限和静态分析，旧行为引导可能迅速过期。
- **【文章陈述】** “Product Overhang”指模型能力跳跃进步，而产品集成渐进更新，因此产品会暂时压住模型已有能力。
- **【文章陈述】** 给模型更难任务、允许探索并要求自行验证，是延长独立运行时间的关键。
- **【证据限制】** 本文为媒体二次整理，本次核验了公开正文，但没有把所有表述视为访谈逐字引用。

**行业意义：** **【主 Agent 推断】** Agent 产品的耐久资产更可能是可重跑的评测、权限边界、观测与验证闭环，而不是持续加厚的 Prompt。模型升级会迫使团队把“定期消融、重建基线”纳入发布流程。

#### 摘要

【文章陈述】文章认为，本体论和语义网技术正在 Agent 工程中重新获得价值：LLM 擅长概率式语言推理，却容易在长循环和工具调用中偏离目标；由类、属性、关系和机器可执行规则构成的本体，可在工具执行后校验推理，把“无界循环”限制在确定边界内。Frank Coyle 建议复用 Schema.org、RDFS、OWL 等成熟标准；Neo4j 则把企业本体分为业务概念、技术元数据和运行轨迹三层，以共享语义层承载更轻的 Agent。文章也没有回避旧语义网的核心失败原因——本体维护昂贵且容易过时。

#### 关键观点与事实

- **【文章陈述】** Frank Coyle 主张以本体作为 Agent 的“逻辑护栏”，在工具运行后用规则或 reasoner 校验 LLM 推理。
- **【可核验事实】** Schema.org、FOAF、Dublin Core、RDFS 和 OWL 均为既有语义网标准；“可直接提示模型复用”的效果来自受访者陈述。
- **【文章陈述】** Neo4j CEO Emil Eifrem 将企业 Agent 本体分为业务本体、技术本体和执行轨迹，并提出“薄 Agent、厚共享语义层”。
- **【文章陈述】** 本体维护和及时更新一直是语义网未普及的主要障碍；让 Agent 根据边缘案例维护本体仍是未解决假设。
- **【主 Agent 核验】** 正文公开完整可读，互动数字可见；文章主要是方法论与案例综述，不构成对本体方案生产效果的统一基准。

**行业意义：** **【主 Agent 推断】** 企业 Agent 可能从纯概率模型转向“模型＋确定性语义层＋可审计执行轨迹”。图数据库和知识图谱的价值可能上升，但若缺少版本治理、冲突处理与持续维护，本体只会把幻觉风险换成陈旧规则风险。

#### 摘要

【文章陈述】文章介绍 World Labs 收购机器人仿真公司 SceniX 后发布的 Real-to-sim-to-real（R2S2R）引擎。系统先把现实机器人、传感器、物体与交互重建为任务对齐的仿真，再在仿真中训练、寻找失败状态、筛选策略并迁移回真实硬件。官方称展示策略完全没有使用真实世界训练数据，却可迁移到 ALOHA、RB‑Y1、YAM、Flexiv、xArm 等平台；多项线缆、试管与抓取任务连续自主运行一小时，且仿真评估能保持不同策略在真机上的相对排名。关键不在用仿真替代所有现实数据，而在建立可复用的训练和评估基础设施。

#### 关键观点与事实

- **【可核验事实】** [World Labs 官方文章](https://www.worldlabs.ai/blog/real-to-sim-to-real)将 R2S2R 分为 Real-to-Sim 与 Sim-to-Real，并描述现实部署结果反哺仿真和策略的闭环。
